Pydantic

介绍

Pydantic 是 Python 的 数据校验与设置管理 库。用类型注解定义数据模型，运行时自动完成解析、校验与序列化。

核心能力：

  • 基于类型注解的运行时校验（str、int、Optional、嵌套模型等）
  • 自动类型转换（如 "123" → 123）
  • JSON Schema 生成（FastAPI OpenAPI 文档依赖此能力）
  • 序列化 / 反序列化：model_dump()、model_validate()、model_dump_json()
  • 字段级与模型级自定义校验器

本文以 Pydantic v2 为准。与 FastAPI 配合时的典型数据流：

HTTP JSON  →  FastAPI  →  Pydantic Schema  →  业务逻辑
ORM 对象   →  model_validate / from_attributes  →  响应 Schema  →  JSON

安装

pip install "pydantic>=2"
# 或
uv pip install "pydantic>=2"

基础用法

1. BaseModel

继承 BaseModel，用类型注解声明字段即可：

from pydantic import BaseModel


class User(BaseModel):
    id: int
    name: str
    active: bool = True  # 默认值


u = User(id=1, name="alice")
print(u.name)       # alice
print(u.model_dump())  # {'id': 1, 'name': 'alice', 'active': True}

# 类型会尽量转换
u2 = User(id="2", name="bob")  # id 变为 int 2

校验失败时抛出 ValidationError：

from pydantic import ValidationError

try:
    User(id="x", name="bob")
except ValidationError as e:
    print(e.errors())

2. Field：约束、默认值、文档

Field 用于约束、默认工厂、OpenAPI 描述与示例：

from typing import List, Optional
from pydantic import BaseModel, Field


class ItemCreate(BaseModel):
    project_id: int = Field(..., description="项目 ID")
    name: str = Field(..., min_length=1, max_length=128, description="名称")
    tags: List[str] = Field(default_factory=list, description="标签")
    weight: Optional[int] = Field(None, ge=0, description="权重")
    status: int = Field(1, description="状态")

常用参数：

参数 说明
`...` / 省略默认 必填字段
`default` / `default_factory` 默认值；可变默认值用 `default_factory`
`ge` / `gt` / `le` / `lt` 数值上下界
`min_length` / `max_length` 字符串 / 序列长度
`pattern` 正则
`description` 字段说明（进入 OpenAPI）
`examples` / `json_schema_extra` 文档示例

3. 可选与嵌套

from typing import List, Optional
from pydantic import BaseModel, Field


class LLMConfig(BaseModel):
    temperature: float = 0.7
    top_p: float = 0.9
    model: str


class ChatRequest(BaseModel):
    question: str = Field(..., description="用户问题")
    llm_config: Optional[LLMConfig] = None
    history: List[dict] = Field(default_factory=list)

嵌套模型会递归校验：llm_config 传入 dict 时自动变成 LLMConfig 实例。

4. 枚举

from enum import Enum
from pydantic import BaseModel, Field


class ChatMode(str, Enum):
    SIMPLE = "simple"
    ADVANCED = "advanced"


class ChatIn(BaseModel):
    mode: ChatMode = Field(..., description="聊天模式")
    question: str

str, Enum 便于 JSON 中直接传 "simple"，也便于序列化回字符串。

校验器（v2）

field_validator：单字段

from pydantic import BaseModel, field_validator


class AppCreate(BaseModel):
    app_type: str

    @field_validator("app_type")
    @classmethod
    def check_app_type(cls, v: str) -> str:
        if v not in ("web", "api", "worker"):
            raise ValueError("unsupported app_type")
        return v

model_validator：跨字段 / 整体加工

mode='after' 在实例已构造完成后再改：

from typing import List, Optional
from pydantic import BaseModel, Field, model_validator


class CancelRequest(BaseModel):
    job_id: Optional[str] = None
    task_id: Optional[str] = None

    @model_validator(mode="after")
    def at_least_one(self):
        if not self.job_id and not self.task_id:
            raise ValueError("至少需要提供 job_id 或 task_id 之一")
        return self


class ChatRequest(BaseModel):
    history: List[dict] = Field(default_factory=list)

    @model_validator(mode="after")
    def prepare_history(self):
        # 清洗 / 截断 / 转换历史结构
        self.history = [
            h for h in self.history if h.get("content") is not None
        ]
        return self

mode='before' 则在解析前处理原始输入（dict），适合改键名、兼容旧格式。

v1 → v2：@validator / @root_validator 已弃用，请改用 @field_validator / @model_validator。

配置 ConfigDict

v2 用 model_config = ConfigDict(...) 替代 v1 的内部类 Config：

from pydantic import BaseModel, ConfigDict


class UserOut(BaseModel):
    id: int
    name: str

    # ORM 对象 → Schema：允许从属性读，而不仅是 dict
    model_config = ConfigDict(from_attributes=True)


class Option(BaseModel):
    id: int
    type: str
    name: str

    model_config = ConfigDict(json_schema_extra={
        "example": {
            "id": 1,
            "type": "api",
            "name": "获取用户信息",
        }
    })

常用项：

配置 说明
`from_attributes=True` 从 ORM / 任意对象属性构造（原 `orm_mode`）
`extra='forbid'` 禁止未声明字段
`str_strip_whitespace=True` 自动 strip 字符串
`json_schema_extra` 补充 OpenAPI 示例等

序列化与反序列化

from pydantic import BaseModel


class Item(BaseModel):
    id: int
    name: str
    tags: list[str] = []


item = Item(id=1, name="step", tags=["api"])

# 实例 → dict / JSON
item.model_dump()                          # dict
item.model_dump(exclude_unset=True)        # 只含显式赋值过的字段（PATCH 常用）
item.model_dump(exclude={"tags"})          # 排除字段
item.model_dump_json()                     # JSON 字符串

# dict / 对象 → 实例
Item.model_validate({"id": 2, "name": "case"})
Item.model_validate_json('{"id": 2, "name": "case"}')

局部更新实体时常见写法：

patch = obj_in.model_dump(exclude_unset=True)
# 再把 patch 合并进 ORM / 领域对象

与 FastAPI 配合

FastAPI 把路径参数、Query、Body 自动绑定到 Pydantic 模型，并生成 OpenAPI：

from fastapi import APIRouter
from pydantic import BaseModel, Field

router = APIRouter()


class ChatIn(BaseModel):
    question: str = Field(..., description="用户问题")
    system_prompt: str | None = None


@router.post("/chat")
async def chat(body: ChatIn):
    # body 已是校验通过的 ChatIn
    return {"echo": body.question}

更多路由用法见 fastapi。

最简可运行示例

# demo_pydantic.py
from typing import List
from enum import Enum

from pydantic import BaseModel, Field, ValidationError, model_validator


class Role(str, Enum):
    USER = "user"
    ASSISTANT = "assistant"


class Message(BaseModel):
    role: Role
    content: str = Field(..., min_length=1)


class ChatRequest(BaseModel):
    question: str = Field(..., min_length=1, description="用户问题")
    history: List[Message] = Field(default_factory=list)
    top_k: int = Field(10, ge=1, le=100)

    @model_validator(mode="after")
    def trim_history(self):
        self.history = self.history[-5:]
        return self


if __name__ == "__main__":
    ok = ChatRequest(
        question="你好",
        history=[{"role": "user", "content": "hi"}, {"role": "assistant", "content": "hello"}],
    )
    print(ok.model_dump())

    try:
        ChatRequest(question="", top_k=0)
    except ValidationError as e:
        print(e)

运行：

python demo_pydantic.py

速查：v1 → v2

v1 v2
`class Config: orm_mode = True` `model_config = ConfigDict(from_attributes=True)`
`.dict()` / `.json()` `.model_dump()` / `.model_dump_json()`
`.parse_obj()` / `.parse_raw()` `.model_validate()` / `.model_validate_json()`
`@validator` `@field_validator`
`@root_validator` `@model_validator`
`Optional[X] = None` 仍可用；也可写 `X | None = None`（3.10+）
