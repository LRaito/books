uv

介绍

uv 是由 Astral 用 Rust 编写的极速 Python 包与项目管理器，可替代 pip、pip-tools、virtualenv、pipx、pyenv 等工具。

核心能力：

  • 安装 / 解析依赖：比 pip 快约 10–100 倍
  • 项目管理：pyproject.toml + 通用锁文件 uv.lock
  • Python 版本管理：安装与切换解释器
  • 工具运行：uvx / uv tool（类似 pipx）
  • pip 兼容接口：uv pip ...，现有 workflow 可几乎零改动加速

安装

# 官方独立安装（推荐）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 或通过 pip / pipx
pip install uv
pipx install uv

验证：

uv --version

用法

1. pip 兼容接口

已有 requirements.txt 时，把 pip 换成 uv pip 即可：

# 创建虚拟环境
uv venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
deactivate                  # 退出虚拟环境（activate 后可用）

# 安装依赖（等价 pip install -r）
uv pip install -r requirements.txt

# 安装单个包
uv pip install fastapi

# 查看 / 导出
uv pip list
uv pip freeze > requirements.txt

# 卸载
uv pip uninstall some-package

# 按锁文件精确同步（会移除多余包）
uv pip sync requirements.txt

常用环境变量：

变量 说明
`UV_INDEX_URL` 默认 PyPI 镜像，如清华源
`UV_LINK_MODE` 链接方式；Docker 里常用 `copy`
`UV_SYSTEM_PYTHON` `1` 时允许装到系统 Python（容器内常见）
`UV_CACHE_DIR` 缓存目录
`UV_ENV_FILE` `uv run` 时加载的 `.env` 文件路径
`UV_NO_ENV_FILE` 设为 `1` 时禁止加载 `.env`

国内镜像示例：

export UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
uv pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

给应用进程设环境变量（与是否用 uv 无关，shell 导出即可）：

export APP_ENV=dev
uv run python main.py
# 或一次性：
APP_ENV=dev uv run python main.py

uv run 也可从 .env 加载（后写覆盖先写；同名变量以 shell 环境为准）：

echo 'APP_ENV=dev' > .env
uv run --env-file .env python main.py
# 或多个文件
uv run --env-file .env --env-file .env.local python main.py

完整列表见：https://docs.astral.sh/uv/configuration/environment/

2. 项目管理（pyproject.toml）

适合新项目或逐步从 requirements 迁移：

# 初始化项目
uv init my-app
cd my-app

# 添加 / 移除依赖（自动写 pyproject.toml 并更新 uv.lock）
uv add fastapi uvicorn
uv add --dev pytest
uv remove some-package

# 锁定与同步环境
uv lock
uv sync

# 在项目环境中运行命令（自动 sync）
uv run python main.py
uv run pytest

3. Python 版本管理

uv python list              # 已安装 / 可安装版本
uv python install 3.11      # 安装 3.11
uv python pin 3.11          # 在当前项目固定版本（写入 .python-version）

指定解释器创建虚拟环境并装依赖：

uv python install 3.11
uv venv --python 3.11 .venv
source .venv/bin/activate
python --version            # 应显示 Python 3.11.x
uv pip install -r requirements.txt

说明：镜像里的 python:3.11-slim-bookworm 等是 Debian 基础镜像变体；本地用 uv 装的是同主版本的 CPython，解释器主版本对齐即可。系统库差异（如 LDAP、OpenBLAS）属于 OS 依赖，不是 Python 版本问题。

4. 一次性工具（替代 pipx）

# 临时运行，不永久安装
uvx ruff check .

# 或安装到 uv 的 tool 环境
uv tool install ruff
ruff --version

5. Docker 中使用（可选）

在镜像构建里用 uv 加速安装依赖是常见做法：

RUN pip install uv \
 && UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
    UV_LINK_MODE=copy \
    UV_SYSTEM_PYTHON=1 \
    uv pip install -r requirements.txt

构建时可挂载缓存目录加速重复构建：--mount=type=cache,target=/root/.cache/uv。

常用命令速查

命令 说明
`uv venv` 创建虚拟环境
`uv pip install` 安装包（pip 兼容）
`uv pip sync` 按 requirements 精确同步
`uv init` 新建项目
`uv add` / `uv remove` 增删依赖
`uv lock` 生成 / 更新 `uv.lock`
`uv sync` 按锁文件同步项目环境
`uv run` 在项目环境中执行命令
`uv python install` 安装指定 Python
`uvx` 临时运行 CLI 工具

最简用例

A. 用 uv 装依赖并跑 FastAPI

mkdir hello-uv && cd hello-uv
uv venv
source .venv/bin/activate
uv pip install fastapi uvicorn

cat > main.py << 'EOF'
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"msg": "hello uv"}
EOF

uvicorn main:app --port 8000

访问 http://127.0.0.1:8000/，应返回 {"msg":"hello uv"}。

B. 纯 uv 项目流

uv init hello-uv-project
cd hello-uv-project
uv add fastapi uvicorn
# 编辑 main.py 后：
uv run uvicorn main:app --port 8000
