FastAPI

介绍

FastAPI 是基于 Starlette（ASGI）与 Pydantic 的现代 Python Web 框架，面向 API：类型注解驱动校验、自动 OpenAPI、原生 async/await。

请求链路：

客户端  →  HTTP / WebSocket  →  Uvicorn  →  FastAPI(app)  →  路由 / Depends / 业务
                                                      ↓
                                              Pydantic Schema 校验

与 Flask（WSGI、默认同步）相比，FastAPI 默认走 ASGI，适合高并发 I/O 与 WebSocket；运行时见 uvicorn，请求/响应模型见 pydantic。

核心能力：

  • 路径 / Query / Body / Header / Cookie 自动解析与校验
  • 基于 Pydantic 的请求体、响应模型与 JSON Schema
  • 自动生成 OpenAPI（/docs Swagger UI、/redoc）
  • APIRouter 拆分模块、Depends 依赖注入
  • 同步与异步视图均可；后台任务、流式响应、WebSocket

安装

pip install "fastapi[standard]"
# 仅核心 + 自选服务器：
# pip install fastapi uvicorn
# 或
uv pip install "fastapi[standard]"

[standard] 会带上 uvicorn、CLI 等常用依赖。

基础用法

1. 最小应用

from fastapi import FastAPI

app = FastAPI(title="Demo", version="0.1.0")


@app.get("/")
def root():
    return {"msg": "hello fastapi"}

运行：

uvicorn main:app --reload --port 8000
# 或代码内：
# import uvicorn; uvicorn.run("main:app", host="127.0.0.1", port=8000, reload=True)

访问：

  • API：http://127.0.0.1:8000/
  • Swagger：http://127.0.0.1:8000/docs
  • ReDoc：http://127.0.0.1:8000/redoc

2. 路径参数与 Query

from typing import Optional
from fastapi import FastAPI, Query, Path

app = FastAPI()


@app.get("/users/{user_id}")
def get_user(
    user_id: int = Path(..., ge=1, description="用户 ID"),
    q: Optional[str] = Query(None, max_length=64),
    page: int = Query(1, ge=1),
):
    return {"user_id": user_id, "q": q, "page": page}

类型注解即校验规则；需要约束、描述、别名时用 Path / Query / Body 等。

3. 请求体（Pydantic）

from typing import Optional
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()


class UserCreate(BaseModel):
    name: str = Field(..., min_length=1, max_length=64)
    email: str
    active: bool = True


class UserOut(BaseModel):
    id: int
    name: str
    email: str


@app.post("/users", response_model=UserOut, status_code=201)
def create_user(body: UserCreate):
    # body 已是校验通过的 UserCreate
    return UserOut(id=1, name=body.name, email=body.email)

response_model 会过滤多余字段并写入 OpenAPI；PATCH 场景常用 model_dump(exclude_unset=True)，详见 pydantic。

4. APIRouter 拆分

# routers/users.py
from fastapi import APIRouter
from pydantic import BaseModel

router = APIRouter(prefix="/users", tags=["users"])


class UserOut(BaseModel):
    id: int
    name: str


@router.get("/{user_id}", response_model=UserOut)
async def get_user(user_id: int):
    return UserOut(id=user_id, name="alice")
# main.py
from fastapi import FastAPI
from routers.users import router as users_router

app = FastAPI()
app.include_router(users_router, prefix="/api/v1")
# 最终路径：GET /api/v1/users/{user_id}

5. Depends 依赖注入

from fastapi import Depends, FastAPI, Header, HTTPException

app = FastAPI()


async def get_token(authorization: str | None = Header(None)) -> str:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="unauthorized")
    return authorization.removeprefix("Bearer ").strip()


@app.get("/me")
async def me(token: str = Depends(get_token)):
    return {"token_prefix": token[:8]}

常见用途：鉴权、DB Session、当前用户、分页参数。子依赖可嵌套；Depends 默认按请求缓存同依赖实例。

6. 异常与状态码

from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import JSONResponse

app = FastAPI()


@app.get("/items/{item_id}")
def read_item(item_id: int):
    if item_id <= 0:
        raise HTTPException(status_code=404, detail="item not found")
    return {"item_id": item_id}


@app.exception_handler(ValueError)
async def value_error_handler(request: Request, exc: ValueError):
    return JSONResponse(status_code=400, content={"error": str(exc)})

7. 中间件与 CORS

from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
import time

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 生产应收紧
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.middleware("http")
async def add_process_time(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    response.headers["X-Process-Time"] = f"{time.perf_counter() - start:.4f}"
    return response

8. 同步 vs 异步

@app.get("/sync")
def sync_view():
    # CPU / 阻塞库：跑在线程池，避免堵事件循环
    return {"mode": "sync"}


@app.get("/async")
async def async_view():
    # await 数据库 / HTTP / 文件等 I/O
    return {"mode": "async"}

规则：能 await 的 I/O 用 async def；阻塞型同步库用普通 def（FastAPI 会丢到线程池）。

9. 流式响应（SSE / Streaming）

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import asyncio

app = FastAPI()


async def event_gen():
    for i in range(3):
        yield f"data: {i}\n\n"
        await asyncio.sleep(0.2)


@app.get("/stream")
async def stream():
    return StreamingResponse(event_gen(), media_type="text/event-stream")

聊天、日志推送等场景常用此模式。

应用工厂与生命周期

from contextlib import asynccontextmanager
from fastapi import FastAPI


@asynccontextmanager
async def lifespan(app: FastAPI):
    # startup：连接池、模型加载等
    yield
    # shutdown：关闭连接


def create_app() -> FastAPI:
    app = FastAPI(title="My API", lifespan=lifespan)
    # app.include_router(...)
    return app


app = create_app()

旧版 @app.on_event("startup") 仍可用，新代码优先 lifespan。

生产运行

# 开发
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 生产：多 worker（须用导入字符串）
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

# 或 Gunicorn + UvicornWorker
gunicorn -k uvicorn.workers.UvicornWorker -w 4 main:app -b 0.0.0.0:8000

更多参数见 uvicorn。

最简可运行示例

新建 hello_fastapi.py：

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
import uvicorn

app = FastAPI(title="Hello FastAPI")


class AddIn(BaseModel):
    a: float = Field(..., description="加数 a")
    b: float = Field(..., description="加数 b")


class AddOut(BaseModel):
    sum: float


@app.get("/")
def root():
    return {"msg": "hello fastapi"}


@app.post("/add", response_model=AddOut)
def add(body: AddIn):
    return AddOut(sum=body.a + body.b)


@app.get("/users/{user_id}")
def user(user_id: int):
    if user_id < 1:
        raise HTTPException(status_code=404, detail="not found")
    return {"id": user_id, "name": "alice"}


if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8000)

运行并验证：

python hello_fastapi.py

curl http://127.0.0.1:8000/
# {"msg":"hello fastapi"}

curl -X POST http://127.0.0.1:8000/add \
  -H 'Content-Type: application/json' \
  -d '{"a":1,"b":2}'
# {"sum":3.0}

打开 http://127.0.0.1:8000/docs 可交互调试。

FastAPI 与 Flask 对照（速查）

项 FastAPI Flask
协议 ASGI WSGI（默认同步）
数据校验 Pydantic 内置 手动或扩展
OpenAPI 自动 `/docs` 需扩展
模块拆分 `APIRouter` `Blueprint`
依赖注入 `Depends` 无统一机制
典型服务器 Uvicorn / Gunicorn+UvicornWorker Gunicorn / Waitress

常用概念速查

概念 说明
`FastAPI()` ASGI 应用实例
`APIRouter` 子路由，`include_router` 挂载
`Depends` 依赖注入
`response_model` 响应过滤与文档
`HTTPException` 业务/HTTP 错误
`Path` / `Query` / `Body` / `Header` / `Cookie` 参数声明
`BackgroundTasks` 返回后执行轻量后台任务
`StreamingResponse` 流式 / SSE
`lifespan` 启动与关闭钩子
