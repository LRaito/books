Flask

介绍

Flask 是 Python 的轻量 WSGI Web 框架，核心小、扩展多，适合快速搭 API 与传统服务端渲染站点。

它负责把 HTTP 请求接到你的视图函数上：

客户端  →  HTTP  →  WSGI 服务器(gunicorn/waitress)  →  Flask(app)  →  路由 / 业务

与 FastAPI / Starlette 的 ASGI 路径不同：Flask 默认是同步 WSGI；要异步或 WebSocket，需额外扩展或换 ASGI 栈。本目录 uvicorn 文档对比过两者。

核心能力：

  • 基于装饰器的路由与视图
  • 内置请求 / 响应、会话、闪讯、静态文件与 Jinja2 模板
  • 蓝图（Blueprint）拆分应用
  • 丰富的扩展生态（Flask-SQLAlchemy、Flask-Login、Flask-RESTful 等）

安装

pip install flask
# 或
uv pip install flask

验证：

python -c "import flask; print(flask.__version__)"

基础用法

1. 最小应用

from flask import Flask

app = Flask(__name__)


@app.get("/")
def hello():
    return {"msg": "hello flask"}


if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000, debug=True)

运行：

python app.py
# 或（推荐开发方式）
flask --app app run --debug --port 5000

访问 http://127.0.0.1:5000/，应返回 {"msg":"hello flask"}。

2. 路由与方法

from flask import Flask, request

app = Flask(__name__)


@app.route("/users/<int:user_id>", methods=["GET", "PUT"])
def user_detail(user_id: int):
    if request.method == "GET":
        return {"id": user_id, "name": "alice"}
    return {"id": user_id, "updated": True}, 200


# 等价简写（Flask 2+）
@app.post("/users")
def create_user():
    data = request.get_json(silent=True) or {}
    return {"id": 1, **data}, 201

路径转换器常用：

转换器 说明
`string` 默认；不含斜杠
`int` 整数
`float` 浮点
`path` 可含斜杠
`uuid` UUID 字符串

3. 请求与响应

from flask import Flask, request, jsonify, make_response

app = Flask(__name__)


@app.post("/echo")
def echo():
    # Query：?page=1
    page = request.args.get("page", 1, type=int)
    # JSON Body
    body = request.get_json(force=True, silent=True) or {}
    # Header / Cookie
    token = request.headers.get("Authorization")
    uid = request.cookies.get("uid")

    resp = jsonify({"page": page, "body": body, "token": token, "uid": uid})
    resp.headers["X-App"] = "flask-demo"
    return resp

返回值约定：

返回形式 含义
`str` / `bytes` 文本 / 原始响应体
`dict` / `list` 自动 JSON（Flask 1.1+）
`(body, status)` 带状态码
`(body, status, headers)` 带额外头
`Response` 完全自定义

4. 错误处理

from flask import Flask, jsonify

app = Flask(__name__)


@app.errorhandler(404)
def not_found(e):
    return jsonify(error="not found"), 404


@app.errorhandler(ValueError)
def bad_value(e):
    return jsonify(error=str(e)), 400

5. 蓝图（Blueprint）

把路由按模块拆开，再挂到应用上：

# blueprints/users.py
from flask import Blueprint, request

bp = Blueprint("users", __name__, url_prefix="/users")


@bp.get("/<int:user_id>")
def get_user(user_id: int):
    return {"id": user_id}


@bp.post("")
def create_user():
    return request.get_json(silent=True) or {}, 201
# app.py
from flask import Flask
from blueprints.users import bp as users_bp

app = Flask(__name__)
app.register_blueprint(users_bp)

6. 配置

from flask import Flask

app = Flask(__name__)
app.config["SECRET_KEY"] = "change-me"
app.config["JSON_SORT_KEYS"] = False

# 或从对象 / 环境加载
# app.config.from_object("config.ProdConfig")
# app.config.from_prefixed_env()  # 读取 FLASK_ 前缀环境变量

常用项：

配置 说明
`SECRET_KEY` 会话 / 签名必需
`DEBUG` 调试模式（生产关闭）
`TESTING` 测试模式
`JSON_AS_ASCII` JSON 是否强制 ASCII

7. 应用工厂

多环境、测试、扩展初始化时常用工厂模式：

from flask import Flask


def create_app(config_name: str = "dev") -> Flask:
    app = Flask(__name__)
    app.config.from_mapping(
        SECRET_KEY="dev" if config_name == "dev" else "prod-secret",
    )

    @app.get("/health")
    def health():
        return {"status": "ok"}

    return app


app = create_app()
flask --app "app:create_app" run
# 或工厂带参数：
# flask --app "app:create_app('prod')" run

模板与静态资源（可选）

默认目录：templates/、static/。

from flask import Flask, render_template, url_for

app = Flask(__name__)


@app.get("/page")
def page():
    return render_template("index.html", title="Flask")
<!-- templates/index.html -->
<!doctype html>
<title>{{ title }}</title>
<link rel="stylesheet" href="{{ url_for('static', filename='app.css') }}">
<h1>{{ title }}</h1>

生产运行

开发用 app.run() / flask run；生产请用专用 WSGI 服务器：

# gunicorn（Linux 常见）
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 "app:app"

# waitress（跨平台）
pip install waitress
waitress-serve --host=0.0.0.0 --port=5000 app:app

对比 ASGI 侧（FastAPI）常用组合见 uvicorn：gunicorn -k uvicorn.workers.UvicornWorker。

最简可运行示例

新建 hello_flask.py：

from flask import Flask, request, jsonify

app = Flask(__name__)


@app.get("/")
def root():
    return {"msg": "hello flask"}


@app.post("/add")
def add():
    data = request.get_json(silent=True) or {}
    a = data.get("a", 0)
    b = data.get("b", 0)
    return jsonify(sum=a + b)


if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000, debug=True)

运行并验证：

python hello_flask.py

curl http://127.0.0.1:5000/
# {"msg":"hello flask"}

curl -X POST http://127.0.0.1:5000/add \
  -H 'Content-Type: application/json' \
  -d '{"a":1,"b":2}'
# {"sum":3}

Flask 与 FastAPI 对照（速查）

项 Flask FastAPI
协议 WSGI（默认同步） ASGI（原生 async）
数据校验 手动或扩展 Pydantic 内置（见 [pydantic](pydantic.md)）
OpenAPI 需扩展 自动生成
典型服务器 Gunicorn / Waitress Uvicorn / Gunicorn+UvicornWorker
适合 轻量站点、传统 MVC、简单 API 高性能 API、异步 I/O、WebSocket

常用命令速查

命令 说明
`flask --app app run` 启动开发服务器
`flask --app app run --debug` 热重载 + 调试器
`flask --app app routes` 列出路由
`flask --app app shell` 带应用上下文的交互壳

环境变量：

变量 说明
`FLASK_APP` 应用入口，如 `app` 或 `app:create_app`
`FLASK_DEBUG` `1` 开启调试
