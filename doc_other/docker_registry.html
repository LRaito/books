Docker 私有镜像仓库

使用官方 registry:2 镜像，配合 htpasswd 实现账号密码认证。适合内网或测试环境快速搭建私有仓库。

Compose 配置存放在 $HOME/app/docker-registry，密码文件与镜像数据存放在 $HOME/data/docker-registry。

架构

┌─────────────┐     docker push/pull      ┌──────────────────┐
│  Docker 客户端 │ ────────────────────────▶ │  Registry :5000  │
│             │ ◀──────────────────────── │  (htpasswd 认证)  │
└─────────────┘     docker login          └──────────────────┘
                                                    │
                                                    ▼
                              $HOME/data/docker-registry/data (镜像存储)

快速部署

前置条件

  • 已安装 Docker 与 Docker Compose
  • 开放端口 5000（可按需修改）

文件结构

$HOME/app/docker-registry/
└── docker-compose.yml

$HOME/data/docker-registry/
├── auth/
│   └── htpasswd          # 账号密码文件
├── data/                 # 镜像数据目录（自动生成）
└── certs/                # TLS 证书（可选）

1. 创建目录

mkdir -p $HOME/app/docker-registry
mkdir -p $HOME/data/docker-registry/auth

2. 创建账号密码

使用 htpasswd 生成 bcrypt 加密密码。以下示例创建用户 admin，密码 admin123：

docker run --rm --entrypoint htpasswd httpd:2 \
  -Bbn admin admin123 > $HOME/data/docker-registry/auth/htpasswd

追加用户时，同样使用 -Bbn 输出到 stdout，用 >> 追加到文件：

docker run --rm --entrypoint htpasswd httpd:2 \
  -Bbn user1 pass123 >> $HOME/data/docker-registry/auth/htpasswd

3. docker-compose.yml

在 $HOME/app/docker-registry/docker-compose.yml 中写入：

services:
  registry:
    image: registry:2
    container_name: registry
    restart: always
    ports:
      - "5000:5000"
    environment:
      REGISTRY_AUTH: htpasswd
      REGISTRY_AUTH_HTPASSWD_REALM: Registry Realm
      REGISTRY_AUTH_HTPASSWD_PATH: /auth/htpasswd
    volumes:
      - $HOME/data/docker-registry/data:/var/lib/registry
      - $HOME/data/docker-registry/auth:/auth

4. 启动

cd $HOME/app/docker-registry
docker compose up -d

验证服务是否正常：

curl -u admin:admin123 http://localhost:5000/v2/
# 期望输出：{}

客户端使用

配置 HTTP 仓库（无 TLS 时必做）

Registry 默认走 HTTPS。内网 HTTP 部署时，需在 Docker 客户端配置「非安全仓库」。

Linux — 编辑 /etc/docker/daemon.json：

{
  "insecure-registries": ["192.168.1.100:5000"]
}

将 192.168.1.100 替换为 Registry 所在主机 IP，然后重启 Docker：

sudo systemctl restart docker

Docker Desktop（Windows / macOS） — Settings → Docker Engine，加入同样配置后 Apply & Restart。

登录

docker login 192.168.1.100:5000
# Username: admin
# Password: admin123

登录成功后凭证保存在 ~/.docker/config.json。

推送镜像

# 给本地镜像打 tag（格式：仓库地址/镜像名:标签）
docker tag nginx:latest 192.168.1.100:5000/nginx:latest

# 推送
docker push 192.168.1.100:5000/nginx:latest

拉取镜像

docker pull 192.168.1.100:5000/nginx:latest

查看仓库中的镜像

Registry API 不直接列出所有镜像名，需按仓库名查询 tag：

# 列出 nginx 仓库的所有 tag
curl -u admin:admin123 \
  http://192.168.1.100:5000/v2/nginx/tags/list

启用 HTTPS（可选）

生产环境建议启用 TLS。在 docker-compose.yml 中挂载证书并指定路径：

services:
  registry:
    image: registry:2
    container_name: registry
    restart: always
    ports:
      - "5000:5000"
    environment:
      REGISTRY_AUTH: htpasswd
      REGISTRY_AUTH_HTPASSWD_REALM: Registry Realm
      REGISTRY_AUTH_HTPASSWD_PATH: /auth/htpasswd
      REGISTRY_HTTP_TLS_CERTIFICATE: /certs/domain.crt
      REGISTRY_HTTP_TLS_KEY: /certs/domain.key
    volumes:
      - $HOME/data/docker-registry/data:/var/lib/registry
      - $HOME/data/docker-registry/auth:/auth
      - $HOME/data/docker-registry/certs:/certs

自签名证书快速生成（仅测试用）：

mkdir -p $HOME/data/docker-registry/certs
openssl req -newkey rsa:4096 -nodes -sha256 \
  -keyout $HOME/data/docker-registry/certs/domain.key \
  -x509 -days 365 \
  -out $HOME/data/docker-registry/certs/domain.crt \
  -subj "/CN=192.168.1.100"

启用 HTTPS 后，客户端不再需要 insecure-registries 配置。

常见问题

unauthorized: authentication required

  • 先执行 docker login
  • 检查 $HOME/data/docker-registry/auth/htpasswd 是否存在且挂载正确
  • 确认用户名密码无误（-Bbn 创建时密码区分大小写）

http: server gave HTTP response to HTTPS client

客户端以 HTTPS 访问了 HTTP 仓库。添加 insecure-registries 配置并重启 Docker。

denied: requested access to the resource is denied

镜像 tag 格式错误。推送前必须 docker tag 为 仓库地址/镜像名:标签 格式，且已 login。

修改密码

重新生成 htpasswd 文件后重启 Registry：

docker run --rm --entrypoint htpasswd httpd:2 \
  -Bbn admin newpassword > $HOME/data/docker-registry/auth/htpasswd

cd $HOME/app/docker-registry
docker compose restart registry

清理镜像数据

cd $HOME/app/docker-registry
docker compose down
rm -rf $HOME/data/docker-registry/data/*
docker compose up -d

运维建议

项目 建议
备份 定期备份 `$HOME/data/docker-registry/` 目录
密码 妥善保管 `$HOME/data/docker-registry/auth/htpasswd`
磁盘 监控 `$HOME/data/docker-registry/data/` 占用，镜像层会持续增长
生产 使用 HTTPS + 反向代理（Nginx / Traefik）+ 定期备份
