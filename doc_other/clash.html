Clash Verge 使用教程

Clash Verge 本身不提供任何节点，只是一台「遥控器」。真正让你连上境外网站的，是机场卖给你的那一批服务器。本文先把这两个概念讲清楚，再按 Clash Verge Rev 的界面走一遍：安装、导入订阅、选节点、开代理。

原版 Clash Verge 已停更。现在大家说的 Clash Verge，实际用的是社区维护的 Clash Verge Rev。下文均按 Clash Verge Rev 来写。

1. 客户端和机场分别干什么

整套流程可以看成两层：

浏览器 / git / 其他软件
        ↓
Clash Verge Rev（本机客户端，负责分流、选节点、改系统代理）
        ↓
机场节点（境外服务器，负责把流量转发出去）
  • 客户端：装在自己电脑上。Clash Verge Rev、旧的 Clash for Windows（CFW）、v2rayN 都属于这一层。
  • 机场：在网上卖代理服务的商家。它提供服务器（节点）和一条订阅链接。客户端定期去拉这条链接，才能拿到最新节点列表。

没有机场，Clash Verge 打开后「代理」页是空的，什么也访问不了。没有客户端，机场给你的订阅链接也无处可导入。

2. 什么是机场

「机场」是圈内叫法，不是航空公司。早期有人把代理服务比作「飞机场」：买一张票（套餐），就能从很多航线（节点）里挑一条飞出去。对应到产品上，机场就是按流量或时长收费的代理服务商。

机场卖什么

常见套餐按月或按年，限制总流量（例如 100GB / 月）和同时在线设备数。付费后，后台会给你：

  • 若干节点，分布在香港、日本、新加坡、美国等地
  • 一条 订阅链接（Subscription URL），一般是 https://... 开头，里面带你的 token

订阅链接打开后通常是一份 YAML 配置，里面有节点列表和分流规则。Clash Verge 导入的就是这份配置，不是某个单独的 IP。

机场会不定期增删节点、换 IP。所以订阅需要定期更新，Clash Verge 里可以设自动更新间隔。

怎么挑机场

本文不推荐具体商家。自己选的时候，优先看这几项：

  • 明确提供 Clash / Clash Meta 订阅，不要只能用对方专属客户端
  • 节点覆盖你常用的地区，延迟可接受
  • 流量、同时在线设备数够用
  • 有公告、工单或 Telegram 群，出问题能问到人
  • 能用支付宝 / 加密货币等你方便的方式付款

机场跑路、突然关站并不少见。不要一次充好几年，先买一个月试试。也不要把订阅链接发到群里、贴到截图里，或丢进来路不明的「在线转换」网站——拿到链接的人可以白嫖你的流量，也可以拿去封你的账号。

订阅格式

同一条账号，机场后台往往给出多种格式：Clash、Clash Meta、V2Ray、Surge 等。Clash Verge Rev 用的是 Clash / Clash Meta（Mihomo） 那一条。复制错格式，导入后节点为空或报 YAML 错误。

3. 下载安装

只从 GitHub Release 下载，不要用搜索引擎里那些「汉化破解整合版」：

https://github.com/clash-verge-rev/clash-verge-rev/releases

Windows 一般下 Clash.Verge_x.x.x_x64-setup.exe。不确定架构就选 x64。系统缺少 WebView2、装完打不开界面时，再改用带 fixed_webview2 字样的安装包。

4. 导入订阅

  1. 登录机场网站，在「我的订阅」或「一键订阅」里复制 Clash / Clash Meta 链接。从 https:// 复制到末尾，不要截断。
  2. 打开 Clash Verge Rev，左侧点 订阅（Profiles）。
  3. 把链接贴到顶部输入框，点 导入。也可以点右上角 +，选 From URL，再填名称、链接、User Agent。
  4. User Agent 选 clash-verge 或 ClashMeta。机场靠这个字段判断客户端类型，填错可能下发不兼容的配置。
  5. 更新间隔建议 360～1440 分钟（6～24 小时）。设太勤会被机场临时封 IP。
  6. 导入成功后会出现一张订阅卡片。点一下或双击卡片，让它高亮（绿色圆点或边框），这才算激活。只导入不激活，代理页仍然是空的。

导入报 client error (Connect) 时，改用「订阅链接配置」再试；仍失败可勾选「允许无效证书（危险）」。当前网络访问不到订阅地址时，可先开手机热点再更新。

手里是 YAML 文件而不是链接：把文件拖进窗口，或在订阅页新建本地配置。本地配置不会自动更新。

5. 选节点并打开代理

激活订阅后，左侧打开 代理（Proxies）：

  1. 点延迟测试（闪电图标），选一个延迟较低、能通的节点。节点名带 IEPL / IPLC 的一般是专线，更稳也更贵；普通 / 中转 够日常用。
  2. 回到首页，打开 系统代理，开关变绿。
  3. 路由模式保持 规则（Rule）。国内网站直连，被墙的走代理。只有调试时才用全局（Global）；直连（Direct）等于关掉代理。

用浏览器打开 https://www.google.com 或 https://github.com，能打开就说明系统代理已经生效。

系统代理和 TUN

方式 做什么 适合
系统代理 改操作系统的代理设置，应用自愿去连 浏览器、VS Code、大部分带「使用系统代理」的软件
TUN 装一张虚拟网卡，把流量强制接管 游戏、部分命令行、不认系统代理的软件

先开系统代理确认订阅和节点没问题，再按需开 TUN。TUN 需要先在设置里安装 服务模式（管理员权限），并给内核 verge-mihomo 放行防火墙。不要一上来同时改系统代理、TUN、DNS，出了问题分不清是哪一步。

系统代理管不了 UDP（游戏数据包常见）。这类流量只能靠 TUN。

6. 本地端口

Clash Verge 在本机开一组端口，给其他软件手动填代理用。以设置为准，不要死记网上的数字：

  • Mixed Port：HTTP 和 SOCKS5 共用，优先用这个
  • 旧教程常见 7890，较新版本常见 7897

在 设置 里看当前 Mixed Port。Git、curl、WSL 要手填代理时，指向 127.0.0.1:这个端口。

WSL 里配 git / SSH 代理，见 wsl 科学上网。注意把文中的 7890 换成你设置里实际的端口。

7. 常见问题

代理页没有节点 订阅卡片没激活、链接不是 Clash 格式、或还没点更新。先激活卡片，再点卡片上的旋转箭头手动更新。

浏览器能上，终端不能 系统代理对不认它的程序无效。给该程序单独设 http_proxy / https_proxy，或改开 TUN。

关掉 Clash 后整台电脑没网 系统代理开关没被还原。Windows：设置 → 网络和 Internet → 代理 → 关掉「使用代理服务器」。

端口已被占用 本机还有旧的 Clash、v2rayN 或其他内核。退出它们，或把 Mixed Port 改成空闲端口（如 7898），再重新打开系统代理。

TUN 打不开 没装服务模式，或以普通权限运行。先安装服务模式，必要时以管理员启动一次。

订阅更新后自定义规则消失 每次拉取订阅都会覆盖配置。不要直接改订阅文件，用 Clash Verge 的配置文件预处理 / Merge，把自定义规则 prepend 进去。
